# Maneko 隐私与数据处理说明

**模板版本：** 2026-10-09。应用发布者应在上架前填写运营主体、支持邮箱/联系渠道、实际 API 域名、AI 供应商和公开政策 URL，并核对部署日志、备份与地区处理要求。本文件不是法律意见。

## 数据处理

- **小说与章节：** 用户上传或粘贴的正文会写入所连接 Maneko 后端的数据库；分章内容也保存在数据库。当前上传接口将文本文件读入并解析，不把原始文件另存为一个独立上传文件。
- **漫画生成：** 章节内容会被用于生成分镜脚本/提示。生成请求和提示会交给后端配置的图像模型；图片写入 `COMIC_DIR`。可选供应商包括 Qwen/DashScope、Wanx 和 MiMo。使用的实际模型取决于部署配置。
- **书库与偏好：** 书名、作者、来源、收藏、分类和进度保存在后端数据库。移动端 API 地址、阅读偏好以及部分界面状态保存在设备浏览器存储中。
- **第三方书源：** 搜索和导入会按所选来源向 Project Gutenberg、Wikisource 或其他已配置来源发起请求；URL 导入会由后端访问用户提交的 URL。请只访问你有权使用的内容。
- **连接日志：** 托管平台、反向代理和 AI 服务可能按各自政策保留运行日志或请求数据。Maneko 仓库不设定这些供应商的保留周期。

## 账号、分析和访问边界

当前版本没有账号、广告 SDK、跨应用追踪或产品分析 SDK。后端 API 没有用户认证和按用户隔离；它设计为个人或受控部署。运营者不得将未加网络访问控制的实例公开为多人共享服务，因为连接者可能访问该实例中的书库数据并消耗模型资源。

## 删除与保留

在应用中删除书籍会删除对应数据库记录，并尝试删除该书章节关联的漫画图片。删除操作不保证即时移除部署者备份、基础设施日志或第三方模型服务中的副本。部署者负责选择持久化存储、设置备份及保留周期，并处理相关删除请求。移动端“重置本地数据”仅清除设备上的本地状态，不删除后端书籍。

## 用户责任与联系

不得上传违法内容、无权处理的个人信息或无授权的版权文本。发布者需在此补充支持联系渠道：**[发布者填写联系邮箱或网址]**。有疑问或要求删除服务端数据，请联系运行该 API 的运营者。

## 发布者上架前必须确认

1. 替换联系占位符，公开托管本政策并填写隐私政策 URL。
2. 对照真实的 API、日志、备份、DashScope/图像模型及书源请求更新披露。
3. 完成应用商店数据安全问卷、内容分级和适用地区法律审查。
