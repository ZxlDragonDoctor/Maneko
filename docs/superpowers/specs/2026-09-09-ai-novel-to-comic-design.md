# AI小说生成漫画 Web应用 - 设计文档

## 1. 项目概述

一个基于AgentScope的Web应用，用户上传纯文本小说，AI智能分章节并为每个章节生成日漫风格的漫画图片，实现小说到漫画的实时转换。

## 2. 核心功能

### 2.1 小说上传与解析
- 支持纯文本(.txt)文件上传
- AI智能分析小说内容，自动划分章节
- 识别章节标题、内容边界

### 2.2 漫画生成
- 基于qwen3.8-max生成漫画脚本（分镜描述）
- 调用通义万相(wanx)生成日漫风格图片
- 支持后续扩展用户自选风格

### 2.3 实时预览
- 左侧：小说内容滚动阅读
- 右侧：对应章节的漫画实时展示
- 用户滚动到某章节时，自动触发该章节漫画生成

### 2.4 漫画集管理
- 已生成章节的漫画图片持久化存储
- 汇总生成完整漫画集
- 支持漫画集导出/下载

## 4. 数据模型

### 4.1 Novel (小说)
```python
class Novel:
    id: str                    # UUID
    title: str                 # 小说标题
    content: str               # 原始文本内容
    created_at: datetime
    updated_at: datetime
    status: str                # processing/completed/error
```

### 4.2 Chapter (章节)
```python
class Chapter:
    id: str                    # UUID
    novel_id: str              # 关联小说
    chapter_number: int        # 章节序号
    title: str                 # 章节标题
    content: str               # 章节内容
    comic_status: str          # pending/generating/completed/error
    comic_images: List[str]    # 生成的漫画图片路径列表
    created_at: datetime
```

### 4.3 ComicPanel (漫画分镜)
```python
class ComicPanel:
    id: str
    chapter_id: str
    panel_index: int           # 分镜序号
    script: str                # 分镜描述文本
    image_path: str            # 生成的图片路径
    created_at: datetime
```

## 5. API设计

### 5.1 小说管理
```
POST   /api/novels/upload          # 上传小说
GET    /api/novels                 # 获取小说列表
GET    /api/novels/{id}            # 获取小说详情
DELETE /api/novels/{id}            # 删除小说
```

### 5.2 章节管理
```
GET    /api/novels/{id}/chapters   # 获取小说的所有章节
GET    /api/chapters/{id}          # 获取章节详情
POST   /api/chapters/{id}/generate # 触发章节漫画生成
```

### 5.3 漫画生成
```
POST   /api/comics/generate        # 生成漫画（异步）
GET    /api/comics/{chapter_id}/status  # 查询生成状态
GET    /api/comics/{chapter_id}/images  # 获取章节漫画图片
```

### 5.4 漫画集
```
GET    /api/novel/{id}/comics      # 获取完整漫画集
POST   /api/novel/{id}/export      # 导出漫画集
```

### 6.2 交互流程
1. 用户上传小说 → 后台AI解析分章 → 返回章节列表
2. 左侧显示小说内容，按章节分组
3. 用户滚动到某章节 → 前端检测到 → 调用生成API
4. 右侧显示生成状态（loading → 生成中 → 完成）
5. 生成完成后显示漫画图片

- **UI框架**: React 18+
- **状态管理**: Zustand 或 React Context
- **HTTP客户端**: Axios
- **样式**: Tailwind CSS
- **滚动检测**: Intersection Observer API

## 7. Agent设计

### 7.1 NovelParserAgent (小说解析Agent)
- **职责**: 解析上传的小说，智能分章
- **输入**: 原始文本
- **输出**: 章节列表 [{title, content}]
- **Prompt**: 分析小说结构，识别章节边界

### 7.2 ComicScriptAgent (漫画脚本Agent)
- **职责**: 将章节内容转化为漫画分镜描述
- **输入**: 章节内容
- **输出**: 分镜列表 [{scene, characters, action, dialogue}]
- **Prompt**: 生成日漫风格的分镜描述

### 7.3 ComicGeneratorAgent (漫画生成Agent)
- **职责**: 调用wanx生成漫画图片
- **输入**: 分镜描述
- **输出**: 图片URL/路径
- **实现**: 封装DashScope wanx API调用

## 8. 生成流程

```
用户上传小说
     │
     ▼
┌─────────────────┐
│  NovelParser    │  解析小说，划分章节
│     Agent       │
└────────┬────────┘
         │
         ▼
    章节列表存储
         │
         ▼ (用户滚动到某章节)
┌─────────────────┐
│  ComicScript    │  生成漫画分镜脚本
│     Agent       │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  ComicGenerator │  调用wanx生成图片
│     Agent       │
└────────┬────────┘
         │
         ▼
    图片存储 + 返回前端
```

## 9. 错误处理

- **上传失败**: 文件过大、格式错误
- **解析失败**: AI无法正确分章
- **生成失败**: API调用超时、限流
- **存储失败**: 磁盘空间不足

## 10. 性能优化

- **懒加载**: 用户滚动到章节才触发生成
- **缓存**: 已生成的漫画图片缓存
- **队列**: 并发生成时使用任务队列
- **压缩**: 图片压缩存储
