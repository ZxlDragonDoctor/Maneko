隐私与数据说明 · 更新于 2026-10-09

你的小说由你选择的服务处理

Maneko 是小说阅读与漫画分镜创作工具。若使用他人托管的后端，该服务运营者的实际处理方式也适用。应用发布者须在上架前补充运营主体、联系渠道、API 域名和公开政策 URL。

小说、章节和漫画

上传或粘贴的正文、分章结果、书库信息和阅读进度会存储在所连接后端配置的数据库。章节内容及生成提示可能发送给部署者配置的 AI 模型；生成图片写入后端配置的文件存储。实际的 DashScope/Qwen、Wanx 或 MiMo 等供应商由部署者决定，其处理与保留政策以供应商的现行条款为准。

设备数据与第三方服务

移动端在设备浏览器存储 API 地址、阅读偏好及部分界面状态。书源搜索、链接导入会访问所选的外部书源或用户提交的 URL。托管平台、代理和模型供应商可能保留运行日志；Maneko 不控制其保留周期。

账号、访问控制与分析

当前版本没有账号系统、广告 SDK、跨应用跟踪或产品分析 SDK。后端没有用户认证和按用户隔离，适用于个人或受控部署。请勿将未配置网络访问控制的服务作为公开多人共享后端。

删除与保留

删除书籍会删除对应数据库记录，并尝试删除关联漫画图片；不保证立即清除运营者备份、基础设施日志或第三方模型服务中的副本。移动端重置仅清除本地状态，不删除服务端书籍。存储和备份保留周期由后端运营者负责。

联系与内容责任

请勿上传违法内容、无权处理的个人信息或未经授权的版权内容。发布者须补充联系渠道：[发布者填写联系邮箱或网址]。隐私问题或服务端删除请求请联系 API 运营者。本说明为发布模板，不构成法律意见。
